## โหมดในเมือง
- **สนามวนรอบ (Central Loop):** ขับผ่านประตูสีขาวหน้ากริดเพื่อเริ่ม วิ่ง 2 รอบ 22 ด่าน ได้เงิน/EXP ตามเวลา
- **Street Sprint (H):** ระบบสุ่มปลายทางบนถนนจริง มีด่านทุก 250 studs จำกัด 150 วิ
- **ท้าแข่ง (C):** เส้นทางเกิดบนถนนตรงที่รถอยู่ นับ 3-2-1 ใครถึงด่านสุดท้ายก่อนชนะ คนตามหลังได้ไนตรัสเพิ่ม
- **งาน Taxi / Delivery (E ที่วง):** ส่งไปอีกจุดภายในเวลา ชนแรงถูกหักค่าโดยสาร เฉียดรถจราจรได้ทิป
- **Road Fight (E ที่วงแดง):** บอส 4 คน ใต้ → กลาง → เหนือ → Road King ต้องชนะตามลำดับ ได้ฉายา
- **Night Run / Survival:** ประกาศทุก 15 นาทีจริง (บังคับเริ่มเพื่อเทส: ใน Command Bar ฝั่ง Server พิมพ์ `game.ServerStorage.StartEvent:Fire("nightrun", 20)` หรือ `"survival"`) Survival คัดคนช้าออก 20% ทุกรอบ รถถูกจำกัดสเปกเท่ากัน
- **อู่ (E ที่วงม่วง):** ซื้อรถ/อัปเกรด (อัปเกรดได้แค่ในคลาสเดิม) และเรียกรถส่วนตัว เริ่มต้นมี Hot Hatch ฟรี เงินยังไม่เซฟใน Studio ถ้าไม่เปิด API access
- **เวลา:** 1 วันในเกม = 24 นาทีจริง ล็อกเวลาเพื่อเทส: `game.Lighting:SetAttribute("TimeLock", 21)` (กลางคืน) หรือ `12` / ลบ attribute เพื่อให้เดินต่อ

## สนาม Bira (ขับไปเองได้)
1. ขึ้นรถ กด **G** หรือ **M** แล้วคลิกไอคอน Bira → ขับตามเส้นฟ้าออกถนนพัทยากลาง → สุขุมวิท → ถ.ธรรมศาสตร์ → สนาม (ราว 3–4 นาที)
2. ถึงหน้าสนาม ขับผ่านซุ้มประตู ลานจอด ไปจอดที่วง paddock แล้วกด **P**
3. โหมด: Free Practice / Time Attack (จับเวลา sector, สถิติส่วนตัว) / Circuit Race 3-5-10 รอบ (รอ 25 วิ, กริด, ไฟแดง 5 ดวง, ออกตัวก่อนไฟดับ +5 วิ) / Track Day / Private Room
4. กติกา: ผ่านด่านตามลำดับ ตัดโค้ง-ออกนอกแทร็กเกิน 1 วิ-วิ่งสวน = รอบไม่ valid, pit lane จำกัด 60 studs/s
5. ทางลัด: กด P ในเมืองแล้วเลือก "Travel: Bira Circuit" (วาร์ปไป paddock)

## ยังไม่เทส / รอคุณช่วยดู
- ภาพรวมด้วยตา: หน้าตาสนาม Bira, ถนนเชื่อม, ย่านใหม่นาเกลือ–จอมเทียน, แสงกลางคืน, มินิแมพ
- FPS จริงตอนเล่น (Shift+F5) ในย่านใหม่และที่สนาม
- โหมด 2 คนในสนาม (แข่ง, ห้อง private, ผู้ชม)
- ลงจากรถระหว่าง Road Fight / Night Run กับผู้เล่นจริง
